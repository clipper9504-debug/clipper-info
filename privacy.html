Clipper ("the app") is operated by Noel Piskin, Germany (contact: clipper9504@gmail.com). The app runs only on the operator's own computer.

YouTube API Services

The app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's privacy policy applies: https://policies.google.com/privacy.

Data the app accesses

After the operator signs in with Google, the app can upload videos to the operator's own YouTube channel (scope youtube.upload). The app stores the resulting access token only in a local file on the operator's computer. No YouTube user data of other people is collected, stored, shared or sold. No data is sent to any server operated by the app.

Revoking access

Access can be revoked at any time via the Google security settings: https://security.google.com/settings/security/permissions. Deleting the local token file also removes the app's access.
