Clipper

Clipper is a small personal tool that creates short highlight clips from streams and videos whose creators have given permission, adds original commentary, and prepares title and description so the owner can publish them on his own YouTube channel.

The tool runs locally on the owner's computer. It is used by one person only (the owner) and is not offered to the public. It uses the YouTube Data API only to upload videos to the owner's own channel after he signs in with Google.
